# Sixth forty-perk batch and visible potency modifiers

Forty additional previously Unsupported source cards now have scoped calculations. All remain Partial: a computed probability or event preview is not a complete combat simulation. Definitions remain in the original src/data/Perks.ts, with ordinary status behavior in Buffs.ts / Debuffs.ts. No runtime catalog overlay is introduced.

## Endless Despair visibility

Updated after the user's in-game test: Potencies shows stored values only, e.g. Bleed 0.5 and Poison 0.1. ED belongs to an activated status rather than those stored values. Self-inflicted statuses are excluded even for legacy saved opt-ins. Enemy duration is boosted; enemy DoT potency placement remains unverified and is represented by an explicitly provisional ED estimate in the damage preview. The source/stat damage curve and dP/10 conversion are retained from the copied formula card. See docs/endless-despair.md for current scope.

## Shared behavior

- Other Perk Effects displays the numeric rules, conditional inputs, and resulting event previews for equipped perks. Manual values persist per build/tab and in exported builds; invalid/nonfinite/negative/unknown fields are rejected, and zero remains valid. Unentered values stay unknown instead of being assumed zero.
- Duration previews use the applying build for Contained/Fury and require an explicit Enemy Mob recipient for Slow Leak. Independent percentage-duration factors multiply as a stated builder convention, pending game verification. No expiration, tick count, or automatic status application is inferred.
- Iron Slayer enhancement is stored on the selected Rage, so it adds a fixed 0.2 to that Rage and doubles its duration. It does not grant global Rage potency or stack with itself per perk count. Final manual potency remains final.
- Healing previews are scoped to documented source coefficients plus Heal Boost and separate normal/critical/expected branches. They exclude unknown level, True Balance healing, recipient, and skill-specific factors. Already received healing for Divine Intervention is not multiplied twice. Lifesteal/event previews labelled before healing modifiers do not silently apply them.
- Current-cooldown events are separate from static cooldown: Divinity, Power Surge, and Shamanic Flow use the entered remaining seconds. Heat Drill overrides Lunge's base to 15s before CDR; untested Barrage and uncertain replacement damage remain held and labelled. Magic Surge failures are a manual snapshot, never an automatically reduced base cooldown.
- Savage Combo follows original M1 attack numbers in the combo table, not individual hits. The first-attack baseline and output-conversion ordering for Piercer/Echo Incineration are explicit builder conventions. Piercer leaves unclassified M1 finishers and unrelated ability exceptions held.
- Summon effects are displayed separately from player stats. Swarm/Trusty Servant cap conflicts and higher-stack penalties are unverified. There are no invented summon actors, automatic buff copies, HP changes, or recursive proc chains.

## Validation

Fifty new regression tests cover every selected perk, visible Endless Despair values, source ownership, duration eligibility, shared infusion, flat Protection scaling, per-column combo ramps, exclusions, fractional amounts, unknown inputs, save/restore, and combined isolated snapshots. An older enchant test now obeys Lifesteal's own Cursed/Perk Effectiveness immunity instead of asserting the obsolete scaling behavior. All 503 Node calculator tests and 15 Python catalog tests pass; TypeScript checks pass.

The earlier verbose Endless Despair view was replaced following user feedback; see the compact potency layout described above.

Royal Clerics Crown at 15 Holy Boost with an entered 100 base heal shows 23% critical chance, 100 normal, 116.5 critical, and 103.795 expected healing. Reload preserves the manual input. Iron Slayer Gloves with Fury 2 extends reference Rage from 5 to 10 seconds; selecting its enhancement gives 20 seconds and raises default 0.1 Rage potency to 0.3. That selected enhancement persists on reload. No browser warnings or errors were observed.

Final source-card coverage: 19 Implemented, 268 Partial, 80 Unsupported, with no unmapped cards. Catalog sync remains clean across 957 items and 367 perk cards; four pre-existing held items remain held.
